# Installation

::tip
[template-dms-demo](https://github.com/AntelopeJS/template-dms-demo) already loads this module with everything it needs. Start there to try it.
::

::steps
### Add the module

From the project root:

```bash [Terminal]
ajs project modules add @antelopejs/dms-api
```

The command adds a `dms-api` entry to the `modules` map of `antelope.config.ts` and installs it. To add the entry by hand instead, write it and run `pnpm exec ajs project modules install`:

```ts fragment [antelope.config.ts]
"dms-api": {
  source: {
    type: "package",
    package: "@antelopejs/dms-api",
    version: ">=0.4.0 <1.0.0",
  },
},
```

### Configure it (optional)

Every option has a default; most of them can also be changed later from the [API settings](/docs/modules/api/usage/settings) page. See [Configuration](/docs/modules/api/configuration).

### Restart the backend, then the frontend

Restart the backend first: the module registers its Vue frontend module when it starts. Then restart `ajs dms dev`, or rebuild with `ajs dms build`.

### Open the console

Open **Modules → API**. `/modules/api` redirects to the Overview.
::

## Try it with traffic

The repository's playground sends its demo storefront routes a few hundred requests (healthy, slow, failing and client errors), so every page has something to show:

```bash [Terminal]
pnpm install && pnpm dev          # backend
pnpm frontend:dev                 # dashboard
pnpm --dir playground traffic     # demo traffic
```
