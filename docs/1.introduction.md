# Introduction

`@antelopejs/dms-api` is the API console of the AntelopeJS DMS. It captures the requests your project's API answers and turns them into a health verdict, request logs, per-route statistics, an inferred contract and a tester, under **Modules → API** (`/modules/api`).

![The API Overview: health verdict, routes needing attention, slowest routes and error share](./images/overview.png)

  :::

## How it works

The module hooks into the API provider (such as `@antelopejs/api`) and records each request of your project's routes: method, path, status, timing, captured headers and bodies (size-capped and redacted). It rolls the requests up into per-route, per-day statistics, and prunes both every hour.

The console only counts your API's traffic. Its own calls (`/api/monitoring`), the DMS's calls (`/dms`, the realtime channel, page layouts, session checks, Settings pages) and the DMS console's pages are neither logged nor counted. Calls sent from the Tester are logged, marked as such, and left out of the statistics, the health and the incidents.

::note
This module is the dashboard for your API, not the HTTP server. Your project still needs an API provider such as `@antelopejs/api`, the DMS runtime and a database.
::

## Live by default

The Overview, Request logs and Routes pages have the DMS **Live / Pause** toggle (`L`). Live, the page follows new requests as the DMS realtime channel announces them; paused, nothing is read and the toggle counts what was missed ("Paused · 40 new requests · 2 in 5xx"). See [Live mode](/docs/modules/api/usage/overview#live-mode).

## Requirements

- A DMS backend in a release that implements the `@antelopejs/interface-dms` range in the [README compatibility table](https://github.com/AntelopeJS/dms-api#compatibility), and the `@antelopejs/dms-frontend` renderer in the range declared by `engines["@antelopejs/dms-frontend"]` of `frontend-vue/package.json`. The `ajs dms` CLI refuses to build the module with a renderer outside that range.
- An API provider (`@antelopejs/api`) and a database implementation (`@antelopejs/mongodb`).
- Optional: `@antelopejs/dms-automation`, to use the [automation nodes](/docs/modules/api/extending#automation-nodes).
